### HomeX 是什么 | What is HomeX

**HomeX 是一个面向公寓 / 小区 / 商业写字楼的数字化物业管理与社区运营平台，
帮助物业实现：流程数字化、费用线上化、社区活跃化与服务商业化。**

**HomeX is a digital platform for apartments, residential communities, and office buildings, enabling digital workflows, online payments, active communities, and service monetization.**

### 核心功能 | Key Features

* **数字化物业流程**
  Move-in / Move-out / Work Permit / Gate Pass / Visitor Registration
* **在线缴费与凭证提交**
  物业费、账单在线支付与上传凭证
* **物业自营服务商城**
  装修 / 保洁 / 维修 / 搬家服务上架与购买
* **社区运营工具**
  公告发布、建议收集
* **社区互动**
  社区贴吧：投票 / 求助 / 活动 / 二手市场
